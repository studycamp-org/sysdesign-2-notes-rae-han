# 시스템설계_2 — 개인 정리 저장소

스터디캠프 **시스템설계_2** 스터디의 개인 정리 저장소입니다.
이 저장소는 여러분의 것입니다. 챕터를 읽고 정리한 내용을 자유롭게 쌓아주세요.

## 시작하기

1. 이 저장소를 로컬에 클론합니다.

   ```bash
   git clone <내 저장소 URL>
   cd <저장소 폴더>
   ```

2. 챕터 정리는 해당 챕터 폴더 안에 **새 파일**로 작성합니다.

   ```
   ch01/
   ├── README.md   ← 리더가 제공한 챕터 안내 (수정 금지)
   └── 정리.md      ← 내가 만드는 파일 (루트의 정리양식.md 를 복사해서 시작)
   ```

3. 작성 후 커밋하고 push 하면 제출 완료입니다.

## 새 챕터 받아오기

리더가 새 챕터를 템플릿에 추가하면, 저장소 루트에서 아래 한 줄만 실행하세요.

```bash
./sync.sh
```

- Windows는 Git Bash에서 실행하세요.
- 최초 실행 시 템플릿 원본이 원격 저장소(`template`)로 자동 등록됩니다.

## AI와 함께 설계 연습하기 (system-grill)

이 저장소에는 설계 grill 스킬이 내장되어 있습니다. Claude Code 또는 Codex를 이 저장소에서 열고:

```
시스템 설계 grill 하자
```

라고 요청하면, 챕터를 골라 핵심 설계 결정 6~7개(장마다 다름)를 하나씩 질문받고
**미팅에서 서로 비교할 수 있는 한 장짜리 설계 문서**(20~30분 분량)를 만들 수 있습니다.

- Claude Code: `.claude/skills/system-grill` 을 자동 인식합니다.
- Codex 등 다른 에이전트: 루트의 `AGENTS.md` 안내를 따라 동작합니다.
- 결과 문서는 해당 챕터 폴더에 저장한 뒤 커밋하면 미팅 자료가 됩니다.

## 규칙 (충돌 없이 동기화하기 위한 약속)

- **템플릿이 제공한 파일은 수정하지 않습니다.** (각 챕터의 `README.md`, `sync.sh`, `정리양식.md`, `AGENTS.md`, `.claude/` 폴더, 이 파일)
  - 예외: **`chXX/미팅과제.md`** 는 채워서 제출하는 파일입니다. 자유롭게 수정하세요.
- 내 정리는 항상 **별도 파일**로 만듭니다. (예: `ch03/정리.md`, `ch03/images/...`)
- 이 약속만 지키면 `./sync.sh` 는 항상 충돌 없이 병합됩니다.

## 미팅 과제 제출

- 각 챕터 폴더에 **`미팅과제.md`** 가 미리 들어 있습니다. 그 파일을 채워서 `main`에 push하면 제출입니다.
- **봇의 풀이 시작 공지 이후의 push만** 제출로 자동 집계됩니다. 미리 작성해 두었다면 공지 후 확인 push를 한 번 해주세요.
- 그 외 파일(챕터 정리 등)은 이름 자유이며, 언제 커밋해도 제출 집계에 영향이 없습니다.
