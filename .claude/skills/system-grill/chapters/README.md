# 장 추가 방법

장 하나 = `chapters/chNN/` 폴더 하나. 엔진(`../SKILL.md`)과 결과 양식(`../output-template.md`)은 장 내용을 모른다.
새 장을 넣을 때 엔진에서 고치는 곳은 **`SKILL.md` description의 지원 장·트리거 문구 한 곳**뿐이다.

## 순서

1. `_template/`을 복사해 `chNN/`을 만들고 `chapter.md`를 채운다.
2. 나머지 세 파일을 `ch01/` 형식에 맞춰 쓴다.
   - `scenarios.md`: 시나리오 4개 + 직접 만들기 + 랜덤. 시나리오마다 **교재 가정 하나를 깨는 제약**과 `돌발 상황`.
   - `question-bank.md`: **질문 7개** (요구사항 2 · 초안 설계 3 · 규모 확장 2). 묶음 질문은 소항목 최대 2개, `(묶음)` 표시. 핵심 질문에는 방식별 세부 질문. 맨 위에 시나리오별 계산 정답 표.
   - `knowledge.md`: 용어와 교재 밖 기술 + 교재 기준안 요약 + "시나리오별로 교재 기준안이 흔들리는 지점" 표.
3. `../SKILL.md` description에 장과 트리거 키워드를 추가한다.
4. 한 번 돌려 본 뒤 `status: draft` → `ready`.
5. 설치본(`<vault>/.claude/skills/system-grill/`)에 다시 복사한다.

## 질문 7개를 고르는 기준

- 이 장에서 **사람마다 답이 갈리는 결정**만 남긴다. 교재에 답이 하나뿐인 것은 `knowledge.md`로 보낸다.
- 흐름 서술, 회고처럼 결정이 아닌 것은 질문으로 내지 않는다(마무리 단계에서 진행자가 처리).
- 핵심 질문(★) 1개 = 이 장의 제목이 묻는 바로 그 문제.
