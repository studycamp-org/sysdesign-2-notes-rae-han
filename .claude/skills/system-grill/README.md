# system-grill

「가상 면접 사례로 배우는 대규모 시스템 설계 기초 2」 장별 스터디용 Claude Code 스킬.
장과 시나리오를 고르면 핵심 설계 결정 **7개**를 한 번에 하나씩 묻고(20~30분),
미팅에서 서로 비교하기 쉬운 **한 장짜리 설계 문서**를 만들어 준다.

## 구조

```
system-grill/
├── SKILL.md            # 공용 엔진: 진행 규칙만
├── output-template.md  # 모든 장 공통 결과 문서 양식 (5개 섹션)
├── diagram-guide.md    # 모든 장 공통 설계도 규칙 (mermaid 기본, excalidraw 선택)
├── scripts/excalidraw.py  # 설계도 spec(JSON) → .excalidraw.md 자동 배치
└── chapters/
    ├── README.md       # 장 추가 방법
    ├── _template/      # 새 장 chapter.md 골격
    ├── ch01/           # 1장 근접성 서비스 (ready)
    └── ch02/           # 2장 주변 친구 (draft)
        ├── chapter.md      # 장 설정 (트리거, 파일 이름, 핵심·돌발 질문, 결과 문서 값)
        ├── scenarios.md
        ├── question-bank.md
        └── knowledge.md
```

## 설치

이 폴더를 통째로 `<프로젝트>/.claude/skills/system-grill/` 또는 `~/.claude/skills/system-grill/`에 복사한다.

## 사용

`/system-grill` 또는 "주변 친구 설계 문제 내줘", "근접성 grill"처럼 말한다.

1. 장 선택(요청에 장 키워드가 있으면 자동) → 이름 → 시나리오(S1~S4, 랜덤, 직접 만들기)
2. 질문 7개에 `선택: X / 근거: ...`로 답한다. `힌트` / `패스` / `저장` / `종료` 사용 가능
3. 마무리에서 진행자가 시스템 전체 설계도(mermaid)와 핵심 흐름을 그리고 한 번 확인받는다. 원하면 excalidraw 파일도 만든다
4. 현재 디렉터리에 결과 파일(예: `주변친구설계_<이름>_<날짜>.md`)이 생긴다

## 결과 문서 (모든 장 공통, 80줄 안쪽)

1. 전제 (핵심 숫자 2개 + 교재와 다른 제약)
2. 결정 7개 (선택 / 근거 한 줄 / 감수한 것)
3. 시스템 전체 설계도 (계층별 mermaid, 결정 번호 라벨, 선 3종) + 핵심 흐름 한 줄
4. 교재와 다르게 간 곳 (최대 3개)
5. 미팅 안건 (가장 자신 없는 결정 + 토론 질문 1개)

미팅에서는 같은 시나리오를 고른 사람끼리 `2. 결정 7개` 표를 나란히 놓고 비교한다.
